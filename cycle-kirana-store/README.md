# Cycle & Kirana Store

Responsive React single-page storefront using Tailwind CSS and Lucide React.

## Run

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Vite outputs the static application to `dist/`.

`src/data.js` contains the grocery and workshop directories. `src/main.jsx` contains reusable photo, card, register and order drawer components. `src/styles.css` contains Tailwind utilities and responsive brand styling. Every photo has a local fallback. Selections persist in browser localStorage. WhatsApp opens a prefilled message for customer review; it does not submit automatically.
